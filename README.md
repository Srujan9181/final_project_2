### 🌟 Key Features

* 🖥 **Public Landing Page** for customer interaction

* 🔐 **JWT Authentication** for secure login/signup

* 📋 **Ticket Management Dashboard**

  * View All, Resolved, and Unresolved Tickets
  * Search and Pagination (server-side)
  * Toggle ticket statuses
  * Auto-assign to Admins
  * Assign tickets to specific team members

* 👥 **Team Collaboration Tools**

  * Add/Edit/Delete team members
  * Email-based team invitation
  * Role-based access control (Admins/Team Members)

* 📊 **Analytics Dashboard**

  * Team and ticket performance insights
  * Visualized with graphs (dummy data pre-filled for display)

* 💬 **Live Chat Functionality**

  * Real-time messaging with customers
  * Chatbot widget customization
  * Missed chat timer alert
  * Mobile responsive widget support

* 👤 **Profile Management**

  * Editable profiles for admins and team members
